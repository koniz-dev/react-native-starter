# Issue 49 verification — remove-demo removes every demo reference

Verified on 2026-10-10 on `main` at
[`b02f576`](https://github.com/koniz-dev/react-native-starter/commit/b02f576).
Each "after" run is on a clean worktree of that commit. It shares the repo's
`node_modules`, and `npm run remove-demo` was run first.

## Change

- **`scripts/remove-demo.js`**
  - It now edits docs and config, not only code: `README.md`, `AGENTS.md`,
    `docs/`, `scripts/`, `.maestro/`, and `.env.example`, as well as `app/`,
    `features/`, `shared/`, and `__tests__/`.
  - Markers can be `<!-- @demo remove-block-start -->` in Markdown or
    `# @demo ...` in YAML, shell, and `.env`.
  - A new `@demo uncomment-block` holds text that applies only once the demo
    is gone. `.env.example` uses it for `EXPO_PUBLIC_USE_DEMO_BACKENDS=false`
    and its note, and the e2e runner for its auth backend.
  - It deletes the Maestro flows that need the demo, then itself: its doc,
    its test, and its npm script.
  - It fails if a doc, flow, or env file still names a deleted file.
- **`scripts/check-docs.js`** no longer skips demo paths after removal. A
  stale reference is now reported.
- **Docs.** Every demo passage sits in a `@demo` block. Demo text inside
  tables and code blocks was moved out, because markers can't go there: the
  conventions tree, the Maestro table, and the Make It Yours and scripts
  tables. Text that holds with or without the demo was rewritten to be
  neutral.
- **`init-project`** runs `remove-demo` before it plans its own edits. Both
  edit the README and the docs, and before this change the planned edits
  would have overwritten the removal. It also skips the demo question once
  the demo is gone. Its test now passes on a demo-free tree as well.
