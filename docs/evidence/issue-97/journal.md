# Dogfooding journal: Pocket Notes from react-native-starter v1.1.10 (#97)

Setup: macOS, Node 24.21.0, npm 11.19.0. Cloned from tag v1.1.10 into a
local folder (`~/Playground/rns-dogfood/notes-app`, no GitHub repository).
Fake backend: `scripts/notes-backend/server.js`, with the shapes Connect Your
Backend describes and 60-second access tokens.
