# Issue 11 UAT — Android storage inspection on a rooted emulator (2026-10-04)

Environment: AVD `UAT_Root_API_37` (sdk_gphone64_x86_64, Android 17 / API 37,
`google_apis` image, build tags `dev-keys`), `adb root` (`uid=0`). Expo Go
57.0.9 installed by `npx expo start --android`; Expo Go's app uid is 10234.
Source at commit 12d723e plus the same temporary, uncommitted Home-screen probe
used before ([temporary-probe.diff](uat-ios/temporary-probe.diff)), reverted
afterwards.

This closes the gap left by the Play Store image, where storage could not be
read. Raw storage dumps (ciphertext, Keystore database) were inspected on the
host but deliberately **not committed**; the observations are recorded below
without secret values.

## Verdict

Android: the login token is stored AES-GCM-encrypted with an Android Keystore
key, read back after a process kill, and deleted on logout; AsyncStorage holds
only the non-sensitive profile. Together with the
[iOS simulator Keychain inspection](uat-ios-simulator.md), acceptance
criterion 1 is verified on both platforms at the storage level.
