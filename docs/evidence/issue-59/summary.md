## Notes

- **Expo SDK 58** is published under npm's `next` tag (a beta); `latest`
  is still 57.0.27 ([expo-sdk.log](expo-sdk.log)). Under the support
  policy, the 4-week upgrade window starts when SDK 58 becomes `latest`. The
  monthly review (#60, item 3) checks this.
- **Dependabot security updates** are still disabled. The monthly workflow
  and `audit:check` cover the same ground without automatic pull requests.
  Turning Dependabot on later would be an owner choice, not a gap in the
  gate.
