# Issue 22 verification — user-facing session state and logout

Verified on 2026-10-04.

## Change

- `hooks/useAuthSession.ts` (new): reads the session through
  `authService.isAuthenticated()` / `getCurrentUser()` and returns
  `status` (`loading` / `signedIn` / `signedOut`), `user`, `refresh()`, and
  `logout()`. A storage failure counts as signed out.
- `app/(tabs)/index.tsx`: Home shows "Signed in as {name}" with a
  **Log out** button, or "Not signed in" with **Try authentication demo**. It
  re-reads the session on focus (`useFocusEffect`), so it updates right after
  login.
- Docs: `README.md` (Authentication demo), `docs/how-to.md` (How to Add
  Authentication), `hooks/README.md` (useAuthSession).
