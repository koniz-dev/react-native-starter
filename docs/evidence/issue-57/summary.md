# Issue 57 verification — release readiness (v1.1.1 baseline)

Verified on 2026-10-11 against tag **`v1.1.1`**, which is commit
**`ea6e2a4e1c7c7bb55116654f47e38e6e7a52da96`**. The scope, the changes since
`v1.0.0-mvp`, the non-goals, and the known limitations are in
[release.md](release.md).

## Before v1.1.1

The tag `v1.1.0` (`281be40`) came first. On a clean clone of it, every
automated gate passed ([v1.1.0-attempt/](v1.1.0-attempt/)), but one check
failed. After `npm run remove-demo`, `test:ci` failed 1 of 259 tests, in the
init-project test
([15-remove-demo-gates.log](v1.1.0-attempt/15-remove-demo-gates.log)).

This was filed as
[#58](https://github.com/koniz-dev/react-native-starter/issues/58) (P1),
fixed in `ea6e2a4` (a test-only change), and closed with PASS
([evidence](../issue-58/summary.md)). The e2e workflow runs on `v1.1.0` were
cancelled. Everything below was re-run from scratch on `v1.1.1`.
